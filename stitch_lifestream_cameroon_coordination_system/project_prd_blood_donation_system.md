# PROJECT OVERVIEW: Blood Donation Coordination System (Cameroon)

## Core Objective
A real-time coordination system connecting verified hospitals, eligible donors, and urgent blood requests in Cameroon. Prioritizes speed, trust, local accessibility (low-data), and smart coordination.

## User Roles
1. **Donors:** Register, view nearby requests, track history, toggle availability.
2. **Hospitals/Blood Banks:** Register (requires admin verification), create blood requests, manage inventory.
3. **Admin:** Full system control, verify hospitals, manage users/campaigns, monitor activity.

## Key Features
- **Emergency Blood Request System:** Prominent button, simple form, triggers donor matching.
- **Smart Matching Engine:** Based on blood type, distance, availability, and eligibility.
- **Notification System:** In-app and SMS/WhatsApp ready.
- **Verification System:** Admin approval for hospitals; verified badges.
- **Blood Inventory System:** Track levels (A+, O-, etc.) and highlight shortages.
- **Donor Engagement:** History, points, badges, and leaderboards.
- **Location-Based:** Support for major Cameroon cities (Yaoundé, Douala, etc.).
- **Campaign System:** Manage donation drives by city.
- **Low-Data Optimization:** Lightweight UI, minimal images, mobile-first.

## UI/UX Requirements
- **Style:** Clean, modern SaaS design.
- **Color Palette:** Primary Red (health/emergency), Secondary White/Soft Gray.
- **Layout:** Mobile-first, fast-loading, clear CTAs.

## Tech Stack
- **Frontend:** HTML, Tailwind CSS, JavaScript.
- **Backend/DB:** Node.js/Express or Firebase.
- **Integrations:** SMS API, Google Maps API.
